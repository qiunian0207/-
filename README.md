# 项目工作区说明

这个仓库目前是一个课程与项目混合工作区，既包含课程资料，也包含可运行的文档理解代码。

## 目录概览

- `服务外包代码/doc_processing`：当前主要开发与运行的文档处理系统
- `东莞市2023~2024年国民经济和社会发展统计公报汇总.docx`：示例文档资料
- `2025山东省环境空气质量监测数据信息.xlsx`：示例结构化数据

## 当前可运行项目

主项目位于 [服务外包代码/doc_processing](/workspaces/-/服务外包代码/doc_processing)。

它提供一个基于 Streamlit 的文档理解与报告生成系统，支持两类核心任务：

- 文档或自然语言内容转结构化结果
- 结构化数据转调查报告式文本

项目详细说明请见 [README.md](/workspaces/-/服务外包代码/doc_processing/README.md)。
